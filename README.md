# English OS · 集中式英语学习系统

单文件网页，零依赖。**不装环境、不联网也能用**——下载 `index.html` 双击打开即可，数据存在浏览器 localStorage。

- **在线地址**：https://minj65446-ops.github.io/english-os/
- **仓库里的 `index.html` 是源码**：GitHub 不会渲染 HTML，点开看到的是代码而非页面。要看网站请打开上面的在线地址，或本地打开文件。

## 本地使用

```
下载 index.html → 双击 → 用浏览器打开
```

数据按域名存在浏览器本地，换浏览器或清缓存会丢。用页面内「工具箱 → 导出备份」存 JSON，换设备时导入即可。

## 页面结构

| 章节 | 内容 |
|---|---|
| 01 水平定位 | 5 题自测定到 CEFR A1–C1，结果联动视频库筛选 |
| 02 学习引擎 | 精听 / 跟读 / 泛听 / 输出四条主线的练法 |
| 03 视频库 | 49 个资源：27 个 YouTube 频道 + 22 个国内（B 站等），按水平与技能筛选 |
| 04 12 周路线图 | 四个阶段，含周次进度与阶段预期提示 |
| 05 每日 60 分钟 | 五个时间块，与「手把手」共用同一份记录 |
| 06 工具箱 | 跟读计时器、生词本 SRS、周复盘折线图 |
| 07 手把手 | 分步清单，三档时长：60 / 15 / 5 分钟 |
| 08 为什么是这套安排 | 方法依据 |

## 几个设计取舍

- **不嵌具体视频链接**：视频 ID 会失效，改为频道主页 + 站内搜索页双入口。
- **三档时长都算数**：5 分钟保底版同样计入连续天数。断一天不惩罚，连断两天才提示回归。
- **连续天数不是唯一指标**：同时显示当前连续 / 最长连续 / 累计学习天，断签后不会归零打击。
- **小胜记录墙**：平台期进步不可见，用可回溯的文字证据对抗「我是不是没进步」。
- **理解率自检**：精听后自评四档，低于 50% 建议降难度——太难硬扛练的是忍耐，不是英语。

## 数据键

全部以 `eos.` 前缀存 localStorage：`level` / `days` / `words` / `review` / `stars` / `mini` / `prep` / `miniSteps` / `quickSteps` / `gmode` / `trigger` / `today` / `start` / `sets` / `comp` / `wins`。
导出为 JSON 备份；生词本可导 CSV，字段适配 Anki 与欧路词典。
